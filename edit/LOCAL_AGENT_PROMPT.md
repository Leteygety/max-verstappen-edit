## 2. Исходное видео
Запусти `edit/fetch_fragments.sh`: он скачивает 6 исходных роликов в лучшем качестве
(до 4K) в `media/src/` и режет фрагменты вокруг 79 одобренных моментов в
`media/fragments/<name>__<start>-<end>.mp4` (<=1080p, CRF 16, родной fps, t=0 фрагмента =
<start> секунд источника). Список моментов: `edit/fragments.txt`; кадр
`<name>__<id>_NNN.jpg` из `media/selected` стоит на t = 2*(NNN-1) с в источнике.
Для рендера можно брать и сами полные исходники из `media/src` (с `in` = время в источнике) —
так даже удобнее, фрагменты нужны были для облака.

Проверь разрешение каждого источника (скрипт печатает и пишет в
`media/fragments/sources.txt`). Если источник ниже 1080p или выглядит пережатым (подозрение
на `brazil24_wet__SJ3Z6jw34hw`: розовый тон, графика трансляции), найди лучше то же самое
событие: официальные каналы FORMULA 1 (хайлайты 1080p50) и Oracle Red Bull Racing (4K),
например `yt-dlp "ytsearch5:2024 Sao Paulo Grand Prix race highlights F1"` с тем же
фильтром качества, что в `edit/fetch_sources.sh`.

Можно сдвигать точку входа внутри того же плана на +-3 с, чтобы поймать лучшее движение, и
брать соседние моменты тех же 6 роликов, если они явно сильнее (особенно крупные планы
Макса с движением и проезды машины крупно).

## 4. Музыка (уже проанализировано, сетки проверены — бери их)
Обе версии slowed: темп строго постоянный. Трекер `librosa` дрейфует и на FUNK CRIMINAL
ловит офф-биты, поэтому используй фиксированную сетку (`edit/analyze_audio.py --fixed-tempo`
делает то же самое; ниже точные значения по всему треку).

**FUNK CRIMINAL 2:** период 0.51282 с (117.00 BPM), бит k = 0.5064 + k*0.51282 с.
Кик на каждом бите сетки, снэйр/хэты на полубитах. Структура: интро без баса b0-b6, бас
входит b7 (4.10 с), бас пропадает + райзер b13-b14 (7.17-8.20), **ДРОП b15 (8.199 с)**,
тяжёлый 808 на последнем бите каждой 8-битной фразы (b22 11.79, b30 15.89, b38 19.99,
b54, b62, b70), провал b45-b46 (23.58-24.61), рестарт b47 (24.61), брейкдаун b78 (40.5),
второй дроп b95 (49.22).
Окно 15 с: **b11 (6.147 с) -> b39 (20.506 с)** = 14.4 с: 2 бита разгона, 2 бита райзера,
дроп, три 8-битные фразы. (Можно b7 4.096 -> b39 = 16.4 с, если нужен вход баса.)

**FALL FROM THE SKY PT. 2:** период 0.53914 с (111.29 BPM), бит k = 0.3169 + k*0.53914 с.
Кик на каждом бите, длинные 808. Атмосферное интро до b26, новый слой хэтов b27 (14.87),
бас входит b37 (20.27), **полная тишина b64-b68 (34.82-37.52, 2.7 с)**, **ДРОП b69
(37.518 с)**, 808-фраза b69-b84, провал баса b99-b100 (53.69-54.77), возврат b101.
Окно 15 с: **b56 (30.509 с) -> b85 (46.144 с)** = 15.6 с: 8 битов нагнетания, тишина,
дроп, 16-битная фраза.

Треки очень громкие (FUNK CRIMINAL -1.3 LUFS). В таймлайне ставь `"loudness": -10` и
`"true_peak": -1` — `render.py` сам сделает двухпроходную нормализацию куска.

## 5. Референс: что именно копировать
Референс — горизонтальный TikTok 1024x576, 11 с, ~21 склейка (~0.5 с на план). Два акта:
**машины (0-4.5 с) -> только Макс и эмоции (4.5-11 с)**, бирюзовая вставка ~8.4 с,
ч/б финал последние ~1.4 с. Почти всё — крупные и средние планы с движением; объект
занимает пол-кадра. Покадрово (примерно):

| время, с | что |
|---|---|
| 0.0-0.4 | RB16B едет в лоб, лёгкий наезд |
| 0.4-0.55 | провал в чёрное |
| 0.55-0.75 | машина крупно в лоб, жёлтый поребрик |
| 0.75-1.15 | засвет в белое на проезде |
| 1.15-1.35 | смаз пролёта (почти абстракция) |
| 1.35-1.75 | машина в повороте, проводка камерой |
| 1.75-2.15 | **негатив** (invert) машины в лоб |
| 2.15-2.35 | тёмный силуэт машины |
| 2.35-2.55 | машина сбоку (Австрия) |
| 2.55-2.75 | **негатив** машины сбоку |
| 2.75-3.35 | проводка: машина проходит по трассе |
| 3.35-3.55 | провал / тёмный смаз |
| 3.55-4.45 | общий план, разворот в дыму -> засвет в белое |
| 4.5-4.95 | Макс крупно, тёмный |
| 4.95-5.55 | Макс в шлеме идёт к камере |
| 5.55-5.95 | пролёт машины |
| 5.95-6.35 | смаз -> чёрное |
| 6.35-6.75 | ч/б Макс идёт |
| 6.75-7.15 | Макс в толпе оборачивается |
| 7.15-7.35 | провал / засвет |
| 7.35-8.15 | Макс празднует в шлеме, толпа сзади, глитч-сдвиг в конце |
| 8.15-8.35 | засвет |
| 8.35-8.95 | **бирюзовая** вставка: шлем крупно |
| 8.95-9.55 | Макс, рука вверх, тёмный фон |
| 9.55-10.35 | ч/б толпа / Макс, радиальный смаз-волна |
| 10.35-10.96 | ч/б Макс крупно, рука вверх — финал |

Целевые метрики (`python edit/style_metrics.py <видео> [таймлайн]`, им же меряли референс):

| метрика | референс | цель |
|---|---|---|
| длина плана (медиана; по таймлайну — без него детектор считает вспышки склейками, у референса выйдет 38 / 0.17 с) | ~0.5 с | 0.35-0.6 с |
| быстрое движение в кадре (>1 % ширины/кадр) | 18 % кадров | >= 12 % |
| статичных кадров (<0.1 %) | 27 % | <= 35 % |
| средняя яркость / кадров ярче 150 | 91 / 12 % | 80-100 / 8-15 % |
| насыщенность (медиана) | 8 (3-14) | 6-12, ливрея и шлем цветные |
| вспышки/провалы/негативы (diff>40) | ~4.9 в секунду | 3.5-6 в секунду |

Прошлая попытка (стоп-кадры 640x360, вертикаль) провалилась: 0-2 % движения, кроп
200x360, в 8 раз меньше деталей — это главное, чего нельзя повторять.

## 6. Инструменты в репо
- `edit/render.py timeline.json out.mp4 [--preview] [--from S --to S]` — рендер. Поля
  таймлайна: `fps, width, height, music, music_start, duration, fade_in, fade_out, loudness,
  true_peak, grain, crf, maxrate, bufsize, shots[], fx[]`.
  Шот: `src, t0, t1, in` (время в источнике), `speed` (число или ключи `[[u, v], ...]` по
  0..1 шота — рампы), `reverse, stutter, mblur, interp` (оптический поток для slow-mo),
  `focus` (0..1 или `"auto"`), `fy, zoom` (ключи), `grade`, `exposure`.
  Грейды: `base, cold, warm, bw, teal, bleach, night, none`.
  fx: `{type, t, dur | t_end, amt, env: decay|hold|tri|in|out}`; типы `punch, push, shake,
  whip, zoomtrans, dirblur, zoomblur, rgb, glitch, flash, dip, bloom, exposure, strobe,
  ghost, invert, threshold`. Время — секунды или `"b12.5"` (бит из `beats`-json).
- `edit/build_timeline.py` + `edit/cuts/*.json` — сборщик для стоп-кадров (кадрирование,
  keep-out зон под вшитый таймкод JPG). Для видео расширь его (поля `in`, `speed`, без
  keep-out) или пиши таймлайн видео отдельным файлом `edit/cuts_video/*.json` — главное,
  чтобы было аккуратно и воспроизводимо.
- `edit/verify_render.py timeline.json video.mp4 sheet.jpg` — формат, чёрные кадры,
  попадание склеек, громкость, контакт-лист.
- `edit/style_metrics.py` — метрики стиля из таблицы выше.
- 16:9 -> 16:9: кроп не нужен, `zoom` 1.0-1.3 для панчей. Графику трансляции (таблица
  времени, лоуэр-трэды, плашки FIA) убирай зумом/фокусом или не бери эти секунды.

## 7. Монтаж
- Склейки на биты сетки, отдельные всплески по полубиту; самый большой удар (вспышка,
  панч, сильная тряска) — на дроп, остальные вспышки только на крупных акцентах.
- Перед дропом: рампа скорости (быстро -> 0.3-0.5x прямо перед ударом), стробы/глитч на
  1/8, у FALL FROM THE SKY — тишину держи одним тёмным крупным планом с медленным наездом.
- Акт 1 — машины (проезды крупно, onboard, проводки, смазы, 2-3 негатива, засветы);
  акт 2 — Макс (шлем, идёт, празднует, рука вверх), бирюзовая вставка один раз, ч/б финал.
- Используй настоящее движение: пролёты, `whip`/`dirblur` на проездах, `zoomtrans` на
  панчах, `mblur` при ускорении, `interp` для slow-mo.
- Две версии должны отличаться порядком и длительностями под свою музыку.

## 8. Проверка — обязательно, итерациями
1. Сначала `--preview` (половинное разрешение), смотри контакт-листы (открывай картинки)
   и кадры в моменты склеек и эффектов; правь таймлайн; потом финальный рендер.
2. `verify_render.py`: 1920x1080, нет случайных чёрных кадров (кроме задуманных провалов
   2-4 кадра), склейки на кадре бита, -10 LUFS, true peak <= -1 dBTP, начало и конец чистые.
3. `style_metrics.py` для каждой версии и для `media/reference/ref.mov` (если есть):
   метрики в целевых диапазонах. Если нет — правь и рендери снова.
4. Сравни свой контакт-лист с референсом глазами: крупность, движение, ритм эффектов.
